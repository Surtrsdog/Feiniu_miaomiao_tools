## 零 读之前必须知道的五条

1. **装置数据一直都在，代码从没读过。** 本地关卡文件与官方上游逐字节相同（`md5=72a417c7167ca61250bd394d3775d34a`）。全仓 `predefines`/`tokenInsts` 只有 2 处引用，**都是注释**，零处功能代码，`GameMap` 里连 `devices` 字段都没有。所以这不是「数据缺失」，是**整层功能没写**。

2. **不要一上来就把装置当「不可通行地形」。** 把装置格设为 `blocked` 后，全库 **3028 条路线变成假性不可达**。真实游戏里木箱会被打掉，敌人不会因此永远走不到终点。正确模型见 S2.4。

3. **`blockCnt` 不是判据。** 「道路障碍物」「阻道岩壁」的 `blockCnt` 是 **0** 却明确阻挡；「土石结构」`blockCnt=3` 但挡的是**沙尘暴**不是敌人。真正依据在技能描述里。共 8 处冲突，见 S0.4，**必须人工复核签字，不许 AI 推断**。

4. **`hidden: true` 是「同格 N 选 1」，不是「不存在」。** 全库 5658 个隐藏实例（49.4%）是备选项。不聚合就会画出 N 个重叠图标、阻挡算成 N 个实体。

5. **装置图标一张都没有。** 敌人图标 7192 张、干员 461 张、装置 **0 张**。所以渲染必须走「几何图形 + 中文首字」降级方案，不要写「加载装置图标」的代码。

#### S1.1 新增 `Device` 数据类

```python
@dataclass
class Device:
    """关卡预置装置（predefines.tokenInsts 的一条）。

    位置行列与 GameMap.tiles 同序（都已自上而下），不需要再翻转。
    """
    row: int
    col: int
    token_key: str            # "trap_027_stone"
    alias: str                # "trap_027_stone#1"
    direction: str            # "UP"
    hidden: bool              # 该实例自己的 hidden，不可按类型推断
    category: str             # "A"/"B"/"C"/"D"
    affects_route: bool
    block_cnt: int
    max_hp: int
    operable: bool
    stack_size: int = 1       # 同格 hidden 堆叠数（N 选 1）
```

#### S1.2 `GameMap` 新增字段与方法

```python
#: 关卡预置装置。同格 hidden 堆叠已聚合为 1 条，stack_size 记原堆叠数
devices: List["Device"] = field(default_factory=list)

def device_at(self, row: int, col: int) -> Optional["Device"]:
    for d in self.devices:
        if d.row == row and d.col == col:
            return d
    return None

def route_blocking_cells(self) -> set:
    """所有 affects_route=True 的装置格。传给 analyze_all(blocked=...)。"""
    return {(d.row, d.col) for d in self.devices if d.affects_route}

def operable_devices(self) -> List["Device"]:
    return [d for d in self.devices if d.operable]
```

`_parse_devices` 的实现要求：

```python
def _parse_devices(data: dict) -> List[Device]:
    pre = data.get("predefines")
    if not isinstance(pre, dict):          # 老关卡可能没有，或是 null
        return []
    insts = pre.get("tokenInsts") or []
    if not isinstance(insts, list):
        return []

    cat = _token_catalog()                 # 懒加载 token_catalog.json
    cells: Dict[Tuple[int, int], List[dict]] = {}
    for it in insts:
        if not isinstance(it, dict):
            continue
        key = (it.get("inst") or {}).get("characterKey")
        pos = it.get("position") or {}
        r, c = pos.get("row"), pos.get("col")
        if key is None or r is None or c is None:
            continue                       # 缺字段：跳过，不猜
        try:
            r, c = int(r), int(c)
        except (TypeError, ValueError):
            continue
        cells.setdefault((r, c), []).append(it)

    out: List[Device] = []
    for (r, c), group in cells.items():
        vis = [x for x in group if not x.get("hidden")]
        hidden_n = len(group) - len(vis)
        if vis:
            # 可见项才是真身；同格多个可见 = 真实同时存在，保留全部
            for x in vis:
                out.append(_make_device(x, r, c, cat, hidden=False, stack=1))
        else:
            # 全隐藏 = N 选 1，只保留 1 条
            out.append(_make_device(group[0], r, c, cat,
                                    hidden=True, stack=max(1, hidden_n)))
    return out
```

**聚合规则（必须逐条遵守）：**

| 同格情况 | 结果 |
|---|---|
| 1 个可见 | 1 条，`stack_size=1`，`hidden=False` |
| N 个隐藏，无可见 | **1 条**，`stack_size=N`，`hidden=True` |
| 1 个可见 + N 个隐藏 | 保留**可见那条**，`stack_size=1` |
| M 个可见（M>1） | **保留全部 M 条**（真实同时存在） |

> 第 3 条最容易写错：**不要写 `stack_size = len(group)`**，那会把可见项也算成备选。

#### S1.4 稳健性（每条都要有测试）

|---|---|
| `predefines` 不存在 / `null` | `devices = []`，不报错 |
| `tokenInsts` 是 `null` | 同上 |

#### S2.3 推荐做法：改一处，全局生效

**不要逐个改这 6 个调用点**（漏一个就是「有的页面挡、有的不挡」这种最难查的 bug）。改 `analyze_all` 一处：

```python
def analyze_all(game_map: GameMap, move_speed: float = 1.0,
                blocked: Optional[set] = None,
                allow_diagonal: Optional[bool] = None,
                include_devices: bool = True) -> List[RouteAnalysis]:
    """分析全部路线。

    include_devices=True 时自动并入关卡预置的改路装置（category A）。
    传 False 可复现「装置接入前」的结果，用于回归对照。
    """
    if include_devices:
        blocked = set(blocked or ()) | game_map.route_blocking_cells()
    return [analyze_route(game_map, r, move_speed, blocked, allow_diagonal)
            for r in game_map.routes]
```

同时在 `RouteAnalysis` 上加 `devices_applied: bool`，让上层能分辨这次结果含不含装置。

#### S2.4 **必须同时做**的可破坏语义（漏了这条就是灾难）

**只做「装置 = 永久障碍」的后果（已实测）：**

- 全库 **3028 条路线变不可达**
- 沙盘里敌人会卡死在木箱前永远不动
- 与真实游戏完全不符（技能原文写着「敌人会破坏此障碍」）

**S2 必须实现的最小可破坏语义：**

| 步 | 规则 |
|---|---|
| 1 | `analyze_all` 传 `blocked` 得到「绕路版」路径 |
| 2 | 沙盘推进时，若某敌人被装置挡住且**无路可绕**（`reachable=False`），它停下攻击该装置 |
| 3 | 装置 HP 按敌人 `atk` 与 `attack_interval` 扣减（复用现有伤害公式，**不要新写一套**） |
| 4 | HP ≤ 0 → 该装置从 `blocked` 移除 → 后续敌人走直路 |
| 5 | **已摧毁状态要持久化**，不能每帧重算丢失 |

**S2 先做「能算对时间点」，不做受击动画**（动画属 S5）。

#### S2.5 两个必须知道的坑

**坑 1：`E_NUM` 占位路线——`parse_level` 已经处理好了，别踩回去。**

好梦在何方原始 `routes` 有 53 条，8 条是 `motionMode=="E_NUM"`（坐标全 `(0,0)`、`checkpoints=null`）。`parse_level` **已经丢弃**它们，所以 `gm.routes` 只有 47 条。

**连带影响（很重要）：**

| 事实 | 后果 |
|---|---|
| `Route.index` **≠ 列表下标** | 该关 `index` 是 8…52 和 1000/1001 |
| 必须用 `gm.route_by_index(i)` | 写 `gm.routes[i]` 会取到隔壁那条 |
| 全库有 1980 关存在这种错位 | 涉及 81813 只出怪（52.2%） |
| 该关另有 2 条 `extraRoutes` | 索引 1000/1001，从 `(2,7)`/`(5,4)` 出发（正是那两个三选一格） |

**坑 2：`extraRoutes` 会进 `routes`。** 上面那两个三选一格不是装饰——它们各有一条 `extraRoutes` 出怪路线。所以 S1.3 的聚合不能把隐藏箱整个丢掉。

### S3 渲染层：地图上画出装置（1.5 天）

#### S3.1 三个硬约束

| 约束 | 说明 |
|---|---|
| **静态层缓存键** | `map_render.py:534` 的 `_master_static_key()` **只许包含「沙盘是否激活」这一个布尔量**。加任何逐帧状态会让静态层每帧重建（实测 60 ms/次） |
| **装置图标 = 0 张** | 不能写「加载图标」，只能画几何图形 |
| **渲染顺序** | `render()` = `_scaled` → `_draw_enemies` → `_draw_portal_link` → `_draw_sandbox` → `_draw_spawn_hover` → `_draw_hover_layer` |

#### S3.2 放静态层，不要放每帧

装置位置一关内不变 → **画进 `_ensure_master()`（`map_render.py:549`）的静态合成**。

**为什么是硬要求**：单关最多 91 个装置。按现有测量（1361 敌人 = 933 ms），91 个装置每帧画约 **62 ms/帧**，会再砍 6% 帧率。静态层本来每关只建一次，**零额外开销**。

**但**：`_master_static_key()` **不许加装置状态**（HP / 是否摧毁）。S5 做装置摧毁时，按「静态层只画完好装置，被摧毁的由动态层覆盖」处理，**不要为一个格子重建整个静态层**。

#### S3.3 视觉方案（先做 L2，别一上来做 L1）

| 级别 | 做法 | 前提 |
|---|---|---|
| L1 | 装置图标 PNG（`cell × 0.42`，与敌人图标统一） | 需补 207 张资源，本批次**不做** |
| **L2** | **几何图形 + 中文首字** | 无资源也能做，**本批次采用** |
| L3 | 纯色块 | 太糙，不够用 |

**L2 规格：**

| 类别 | 底色 | 形状 | 标注 |
|---|---|---|---|
| A 改路型 | `#8B5A2B` 棕 | 圆角矩形 | 中文名首字（碎石→「碎」） |
| B 实体阻挡型 | `#6B7280` 灰 | 圆角矩形 | 首字 |
| C 功能型 | `#2563EB` 蓝 | 圆形 | 首字 |
| D 装饰型 | `#9CA3AF` 浅灰 | 小圆点 | **不画字** |

尺寸 `cell × 0.34`（比敌人 `0.42` 小，避免抢视觉）；`alpha=210` 让地形纹理透出；文字白描边 + 深填充，字号 `cell × 0.22`。

#### S3.4 「N 选 1」角标（漏了就是明显 bug）

`stack_size > 1` 时，右下角画 `×N` 角标。

**绝不能把 N 个方块叠画在同一格。** 好梦在何方 `(2,7)`/`(5,4)` 各有 3 个隐藏箱，不聚合会画出 3 个完全重叠的图标（看起来像 1 个但 alpha 叠加会变深，且角标缺失）。

#### S3.5 悬浮提示

沿用 `map_canvas._enemy_at()`（`map_canvas.py:441`）的命中测试模式，新增 `_device_at(row, col)`。
悬浮显示：`中文名 · 类别 · HP/blockCnt · 技能摘要`。
**不做**点击详情弹窗。

### S4 可操作装置（可选，1 天）

用户原话里提到「有些装置是可以操作的」。
