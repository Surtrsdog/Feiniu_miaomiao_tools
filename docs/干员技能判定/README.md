## 判定链的匹配方式

| 层级 | 依据 | 可靠性 |
|---|---|---|
| A | 技能 `blackboard` 的键名直接含模板名，如 `mlyss_s_1[cost].cost` | 最可靠，游戏自己写的 |
| B | 命名规则 `skchr_<X>_<n>` → `<X>_s_<n>` 或 `<X>_s<n>` | 较可靠，已用数值一致性抽查 |
| D | 匹配不到 | 标注为「没有独立 buff 模板」 |

> **诚实说明**：游戏 `skill_table` 只给 `prefabId`，真正的技能→模板绑定存在不可解的 `.ab` 包里。
> 本目录的归属是按命名规律 + `blackboard` 键名双向推断的，不是游戏直接给出的字段。
