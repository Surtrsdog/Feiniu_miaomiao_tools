## 四、二技能的蓄力判定（重点）

二技能是 `maxChargeTime = 2` 的双层充能技。蓄力版靠一个**标记 buff** 判定，逻辑分两步：

**第一步 — 开技能时判断要不要挂标记**（`chen2_s_2_enhance_judge`，事件 `ON_BUFF_START`）：

```
ON_BUFF_START
  ├─ IfElse
  │     condition: CompareCharSkillAvailableCnt  _condType=GE  _count=2
  │                （当前可用技能次数 ≥ 2）
  │      成立   → CreateBuff  挂 chen2_s_2_enhance_mark（lifeTimeType=INFINITY）
  │      不成立 → 不挂
  │
  └─ ClearCharacterSp    ← 与 IfElse 同级，无条件执行：清空 SP
```

**第二步 — 主模板读标记决定走哪个模式**（`chen2_s_2`）：

```
ON_BUFF_START
  └─ IfElse
        condition: CheckContainsBuff  _buffKeys=["chen2_s_2_enhance_mark"]
        ├─ 有标记 → SwitchMode(_modeIndex=3)   蓄力版
        └─ 无标记 → SwitchMode(_modeIndex=2)   普通版

ON_BUFF_FINISH
  └─ SwitchMode(_modeIndex=0, _restoreDefault=true)   技能结束恢复默认模式
```

| 版本 | 弹药数 | 数据依据 |
|---|---|---|
| 普通 | 8 发 | `attack@trigger_time` = 8 |
| 蓄力 | 20 发 | `attack@another_trigger_time` = 20 |

**判定含义**：`_count=2` 对应 `maxChargeTime=2`。**攒满两层再开**才吃蓄力加成，只攒一层就开是普通版。

## 五、粘液（debuff）的判定细节

模板 `chen2_s_debuff`（二、三技能共用）：

```
ON_BUFF_START
  ├─ VertifyTarget    先筛目标
  │     targetOptions.targetSide   = ENEMY       只对敌方
  │     targetOptions.targetMotion = WALK_ONLY   只对地面单位
  └─ CreateBuff       给通过筛选的目标挂 buff
        buffKey     = "chen2_slime"
        templateKey = "empty"        纯属性修改，无行为树
        MOVE_SPEED  FINAL_SCALER   移速乘算
        DEF         FINAL_ADDITION 防御加算
        两者 loadFromBlackboard = true → 数值实时取自技能 blackboard
```

**关键**：`targetMotion = WALK_ONLY` 就是「地面敌人经过时」的判定依据，飞行单位不触发。

| 取值 | 二技能专三 | 三技能专三 |
|---|---|---|
| `attack@move_speed` | -0.35（移速 ×0.65） | -0.45（移速 ×0.55） |
| `attack@def` | -170 | -220 |
| 粘液持续 | 5 秒 | 5 秒 |

**不叠加的原因**：`chen2_slime` 的 `maxStackCnt = 1`、`overrideType = "EXTEND"`
→ 同一目标只保留 1 层，重复命中只刷新持续时间，不叠强度。对应描述「（不叠加）」。

import json
G = r"<解包目录>/zh_CN/gamedata"

ct = json.load(open(G+r"\excel\character_table.json", encoding="utf-8"))
d  = ct["char_1013_chen2"]["phases"][-1]["attributesKeyFrames"][-1]["data"]
print(d["baseAttackTime"], d["atk"], d["attackSpeed"])

st = json.load(open(G+r"\excel\skill_table.json", encoding="utf-8"))
lv = st["skchr_chen2_2"]["levels"][-1]
bb = {b["key"]: b["value"] for b in lv["blackboard"]}
print({k: bb[k] for k in ("atk","attack@trigger_time","attack@another_trigger_time")})

bt = json.load(open(G+r"\battle\buff_template_data.json", encoding="utf-8"))
j  = bt["chen2_s_2_enhance_judge"]["eventToActions"]["ON_BUFF_START"][0]
print(j["_conditionNode"]["_condType"], j["_conditionNode"]["_count"])   # GE 2
print(j["_succeedNodes"][0]["_buff"]["buffKey"])                          # chen2_s_2_enhance_mark

db = bt["chen2_s_debuff"]["eventToActions"]["ON_BUFF_START"]
print(db[0]["_targetOptions"]["targetMotion"])                             # WALK_ONLY
print(db[1]["_buff"]["buffKey"])                                           # chen2_slime

bk = json.load(open(G+r"\bakemuzzledata\character\char_1013_chen2_defaultskin.json", encoding="utf-8"))
for tr, tv in bk["bakedAnimDatas"].items():
    for an, av in (tv.get("bakedEvents") or {}).items():
        if "OnAttack" in av["events"]:
            print(an, av["eventTime"])
