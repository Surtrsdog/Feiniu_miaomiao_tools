肥牛妙妙工具 · 2.1
====================================

明日方舟 伤害计算 / 寻路分析 工具

安装位置
------------------------------------
默认装在  %LOCALAPPDATA%\FeiNiuMiaoMiao
（即 C:\Users\你的用户名\AppData\Local\FeiNiuMiaoMiao）

为什么不在 Program Files？
本程序是单文件 exe，首次运行时会在自身旁边生成 data\cache
（约 34MB 的关卡与敌人数据）。Program Files 默认不可写，
放那儿会导致缓存被重定向到别处，卸载时也清不干净。


首次启动
------------------------------------
直接双击桌面的「肥牛妙妙工具」即可，无需安装 Python，
也无需联网——所有数据都已内置。


功能
------------------------------------
· 伤害计算：单次伤害 / DPH / DPS，支持曲线、对比模式
· 寻路分析：读关卡地图，按格子绘制敌人路线与罚站点
· 敌人图鉴：技能名 + 中文描述 + 解包代码注解
· 数据字段图鉴：黑board 参数、机制、状态机


已知情况（2.1）
------------------------------------
· 敌人技能名与解包 prefabKey 的对应，目前覆盖约 56%，
  其余留空不猜——宁可空着，也不给错结论
