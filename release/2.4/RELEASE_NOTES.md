# 肥牛妙妙工具 v2.4

## 这次的重点：抬手改成「帧 + 秒」双单位

以前只给秒，但游戏里说抬手都是说帧（「这怪抬手 14 帧」）。现在两个都给：

- 敌人图鉴的抬手卡片：`抬手 14 帧　（0.467 秒）`
- 卡片底部注明换算依据：`按 30 帧/秒 换算；1 帧 ≈ 0.033 秒`

**帧数是原始数据，不是估算出来的。** 解包 `bakemuzzledata` 的动画按
30 帧/秒烘焙，`eventTime` 本质就是「帧号 ÷ 30」。对全部 1857 条实测，
换算再换回来误差 < 0.001 帧（只是 JSON 存 4 位小数造成的）。

## 新增：单位换算

两个地方都能换：

1. **设置 → 抬手单位换算**：输数字、选帧/秒，实时出结果
2. **MCP 新工具 `attack_timing_convert`**：换算、查敌人抬手、出换算表

## 新增：MCP 接口配置搬进设置

设置窗口多了一张「MCP 接口」卡：

- 显示当前可用的命令和 `19 个工具　协议 2024-11-05`
- **复制配置** 一键把 JSON 放进剪贴板
- **自检** 按钮，不装任何客户端也能确认服务端活着

MCP 工具从 18 个增加到 19 个，`enemy_attack_timing` 的返回值也补了
`attack_windup_frames` / `by_animation_frames` / `fps`（旧的秒字段保留）。

## 顺手修掉的几个真问题

这几个不修的话，属于「平时看不见，一踩就致命」：

**1. 设置窗口在小屏上点不到「完成」**
加了新卡片后窗口内容高到 855px，原来是固定尺寸不能拉。1366×768 的
笔记本上，底部「完成」按钮直接被挤出屏幕外，还拖不动——等于卡死。
现在可自由调整大小，内容可滚动，底部按钮固定常驻，高度自动夹到屏幕内。

**2. `--mcp --self-test` 一直是崩的**
`W = sys.stderr.write` 取到的是方法不是流，最后一行 `W.flush()` 必然
`AttributeError`。因为崩在最后一行，前面响应都正常打印，看着像「跑完
了但退出码 1」，很容易被漏掉。已修，并让它真的返回成功/失败码。

**3. MCP 工具列表可能静默少一半**
判断「工具模块加载没」用的是注册表空不空。只要有任何地方先单独
`import` 了一个 tool 模块，剩下三个就永远不加载，18 个变 6 个，
而且调不存在的工具才报错。已改成独立标志位。

**4. 「检查更新」失败时会 NameError**
`settings_dialog.py` 用了 `WARN` 但从来没 import 过。这条路径平时不走到。

**5. MCP 传错参数名时提示看不懂**
`map_get` 传 `{"query": "4-4"}`（跟 `map_search` 混了）会回
「关卡索引里找不到：''」，让人以为是关卡不存在。现在会明确说
「缺少 level 参数」并指出你传的是 query。
