# 肥牛妙妙工具 v2.2

本次是「沙盘推演」与「图鉴」的大版本更新，同时修复了打包后才会暴露的一批问题。

## 下载哪个？

| 文件 | 适用场景 |
| --- | --- |
| `FeiNiuMiaoMiao_2.2_setup.exe` | **推荐**。双击安装，自动创建开始菜单与桌面快捷方式，可正常卸载 |
| `FeiNiuMiaoMiao_2.2_portable.exe` | 免安装，单个 exe 直接跑。放在任意可写目录 |

两个文件内容相同（都是同一个程序），只是安装包多了快捷方式和卸载功能。
首次启动会在 exe 同目录释放约 400MB 的关卡与图标缓存，需要等几秒。

## 沙盘推演

从零搭建的推演面板，用来复盘一局的部署顺序与敌人走位。

- **底部粗轴**记录干员部署与撤退，和游戏内时间轴对应
- **右键部署**：高台/地面按关卡可部署区域校验，非法位置直接拒绝；
  地面干员挡地面敌人，飞行干员可挡飞行敌人
- **阻挡按真实阻挡数结算**：每名干员有各自的 `block_count` 配额，不是
  一律挡 1 个；被挡的敌人会被真正拦在格子上
- **悬停敌人**显示阻挡/罚站状态与剩余罚站时间
- **悬停干员**显示技能 SP 回转进度
- **右键干员**撤退或开技能（技能只模拟 SP 回转与持续时间，不算伤害）
- **右键敌人**设置减速或 buff，影响动画播放
- **撤销/重做**：`Ctrl+Z` / `Ctrl+Y`，界面上也有「撤一步」「重做」按钮
- **导出/导入**：粗轴 + 关卡 id 存成 JSON，可以发给别人复现
- 悬停特殊地块与装置显示名称；点击传送门显示传送路径
- 箱子不会堵死通往蓝门的全部路线

## 图鉴

- **敌人天赋与能力描写**补齐（接 `enemy_handbook_table.json`，
  1644 条 `abilityList`）。之前图鉴里敌人只有数值，一句描述都没有
- **新增「代码实现」卡**：从解包数据反推这个敌人/技能在代码里是怎么
  实现的（`prefabKey`、`blackboard` 参数），并明确标注哪些是反推结论
- **批注功能**：干员和敌人都能写备注，可分别导入导出 JSON
- **图标**：干员头像 461/461 全部命中，敌人 98.94%（剩下 19 个是解包
  数据本身就没有素材）
- 敌方技能描述对齐 PRTS 格式与措辞

## 打包相关（之前 exe 版才有的问题）

这些 bug 源码跑完全正常，只有打包后才炸，所以这次一起修了：

- **20 个模块没打进包**，其中 5 个是函数内延迟导入，PyInstaller 静态
  分析看不见，缺了就是运行时 `ModuleNotFoundError`
- **图鉴天赋整片空白**：`enemy_handbook_table.json` 没随包，
  复制那一步静默跳过了
- **召唤物下拉只剩「不计入」**、**集成战略分类全空**：同样是
  文件没复制到可写目录。原因是 spec 的打包清单和
  `paths.seed_if_needed()` 是两份独立白名单，必须成对维护
- **图标全没打进去**，干员头像会退回名字缩写。现在带
  `operator/128` + `enemy/96` 两档，读取改成「可写目录优先 +
  只读包内兜底」，84MB 图标不必复制到磁盘
- exe 属性里现在能看到版本号 `2.2.0.0`
