# v2.1

## 2.1

### 安装
下载 **肥牛妙妙工具_2.1_安装包.exe** 双击即可，无需 Python、无需联网。

默认装在 `%LOCALAPPDATA%\FeiNiuMiaoMiao`（不装 Program Files，因为程序首次运行要在自身目录生成 34MB 缓存，Program Files 没写权限）。卸载会连带清掉缓存。

不想安装？直接下 `肥牛妙妙工具.exe`，单个文件双击就能跑。

### 这个版本做了什么

寻路分析、敌人图鉴与数据表本版没有改动，修改集中在伤害计算层。

**混伤按类型分别计算**
- 以前一次攻击只要带法术倍率，整套伤害就被当成单一类型，物理那部分按法术抗性去减。
- 现在物理、法术各自吃自己的抗性（物理吃防御与物穿，法术吃法抗与法穿），算完再相加。
- 面板上 `物理伤害 DPH / DPS` 与 `法术伤害 DPH / DPS` 分行列出，两者之和等于总 DPS。
- 曲线图同步分出「物理伤害」「法术伤害」「总量」三条线，能直接看出打高防时是物理塌了还是法术塌了。
- 已核对：号角 S2 物理 862.3 + 法术 215.6 = 1077.9；瑕光 S3 1016.8 + 1016.8 = 2033.5。

**模组属性可以选了**
- 新增模组下拉框与等级选择。以前模组的攻击、防御、攻速等加成完全不参与计算。
- 「基础证章」这类初始模组不出现在列表里，避免和白板重复。
- 选模组后面板数值即时变化（史尔特尔 772 → 832）。

**上方面板改为 0 防御 / 0 法抗基准**
- `单次伤害 / DPH / DPS` 现在固定是零抗性下的数值，改目标防御法抗不再动它。
- 这样同一张面板可以横向比较不同干员，不会因为各自填了不同的目标抗性而失去可比性。
- 想看实际打某个目标的结果，看 `按目标实算` 那一行，它跟着目标抗性走。

**法术穿透与物理穿透被动**
- 从天赋里解析固定/百分比穿透，并按精英阶段取正确的档位。以前天赋的穿透完全没进公式。
- 史尔特尔「熔火」26 点法穿、迷迭香「共鸣」220 点物穿、送葬人「送葬」210 点物穿都会生效。
- 新增 `穿透` 行，直接写出「无视多少、有效抗性从多少到多少、单次伤害从多少到多少、多了多少」。
  例如史尔特尔打 60 法抗：`有效法抗 60 -> 34，单次伤害 1327.84 -> 2190.94（+863.096）`。
- 目标本来就没抗性、或穿透之后仍触底到 5% 保底时，不显示这条提示——那时候穿透确实没有收益。
- 条件触发的穿透（如「生命值高于 XX% 时」）不参与计算，宁可不算也不给错的数。

**召唤物伤害**
- 新增召唤物支持：67 个 token 里 28 个会实际输出，覆盖 24 位干员。
- 面板新增召唤物下拉与数量选择（1–5），切换技能会自动选中对应召唤物
  （令 S1/S2/S3 → 清平/逍遥/弦惊；麦哲伦 S2/S3 → 龙腾.L/龙腾.A）。
- 本体与召唤物是两条独立攻击流：攻击力、攻击间隔、伤害类型、穿透都各算各的，算完再相加。
  面板同时给出本体数值、召唤物数值、合计与召唤物占比。
- 曲线图叠加「召唤物·XX」与「本体 + 召唤物」两条线，十种曲线类型都支持。
- 修了两个相关 bug：
  - 医疗干员分支会把召唤物伤害一起抹掉。凯尔希本体只治疗，但 Mon3tr 是真的在打（1402 攻），
    以前那 701 DPS 直接消失。现在只有没有攻击型召唤物时才显示「—（医疗干员）」。
  - 「医疗探机」atk=125 过了阈值，被当成攻击型召唤物，凭空多出 500 DPS。改为按名字排除治疗/装置类。

**不再把所有技能笼统当成单一类型**
- 按技能 blackboard 里的倍率键判定：`atk_scale` 是物理、`magic_atk_scale` 一类是法术，同时存在就是混伤。
- 停手类技能（描述含「停止攻击」）不再套用攻击力倍率。
- 「造成法术伤害」这类只在召唤物光环描述里出现的情况，不会再影响干员本体的类型判定。

### 已知情况
- **澄闪、荒芜拉普兰德的浮游单元算不出来**：官方数据里它们是 `funnel` 分支，浮游单元不是独立实体，
  拿不到攻击力与间隔，因此不建模。
- **对比模式不读天赋穿透**：对比模式只吃拐提供的穿透，天赋的固定穿透没有并进去。
  单干员面板是完整的。
- **召唤物技能倍率未套用**：部分召唤物自身技能带倍率（梅尔水獭 S2、令逍遥的 2 阶段递增），
  目前按基础攻击力算，这部分会偏低。
- 条件触发的天赋穿透、潜能加成里的穿透条目不参与计算。
