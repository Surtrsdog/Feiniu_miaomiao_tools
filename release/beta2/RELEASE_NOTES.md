# v1.0 之前的说明
## beta2

### 安装
下载 **肥牛妙妙工具_beta2_安装包.exe** 双击即可，无需 Python、无需联网。

默认装在 `%LOCALAPPDATA%\FeiNiuMiaoMiao`（不装 Program Files，因为程序首次运行要在自身目录生成 34MB 缓存，Program Files 没写权限）。卸载会连带清掉缓存。

不想安装？直接下 `肥牛妙妙工具.exe`，单个文件双击就能跑。

### 这个版本做了什么

**敌人图鉴：技能名 + 解包代码注解**
- 技能卡按 PRTS 排版：技能名、冷却/初始/消耗、中文描述
- 描述下面用 `↳` 挂对应的 `prefabKey` 和参数表
- 新建 `enemy_skills_prts.json`（623 个敌人 / 1041 条技能），用「初始冷却」这个唯一强锚点把中文技能名和解包 `skills[]` 对上
- 覆盖率 24.8% → 56.0%（439 条里配上 246 条，其中 216 条有数值证据）
- **配不上就留空，不猜**。两个技能名抢同一套参数时两个都不给——配错比不配更糟

**设置：检查更新**
- 从 GitHub Releases 读最新版本号，后台线程发请求，不卡界面
- 版本号比较按 `v?主.次[-后缀]` 切段，所以 `beta10 > beta2` 而不是字符串比大小
- 只给下载链接，不自动替换 exe（运行中的单文件程序在 Windows 上改不了自己）
- 顺手修了个 DNS 超时坑：`urlopen(timeout=)` 只管连上之后的读写，DNS 解析不受约束，国内会卡到系统默认 21 秒
- 版本号 beta1 → beta2

**寻路分析：路线图只画选中的那条**
- 未选中敌人时不画任何路线（以前 43 条线全画，糊成一团）
- 「本关出怪」右侧新增「清空路径」
- 罚站标记只出现在单路线视图

**可读性**
- `FG_DIM` 提亮到 `#aab6c6`（对比度 6.23 → 7.57）
- 等宽强调文字改用 `ACCENT_TXT #8fc2f0`（9.2:1）
- 数据字段图鉴配色同步
- 寻路分析、各图鉴页的强调色与悬停色统一到 `ACCENT #4ea1f7`，和伤害计算一致

**新增：沙盘推演**
- 主界面第三个入口。选关卡后可以在地图上摆干员、放箱子、踢敌人、加减速，
  实时看路线改道与到达时间变化
- 四条规则都按游戏实际行为做的，不是想当然：
  - **只有箱子改路径**。干员在游戏里是碰撞级阻挡——敌人照原路走过来撞上才停，
    不会提前绕路。所以干员永远不进寻路阻挡集（main_16-11 上摆满一列，
    8 条路线的总时间与总长度逐位不变）
  - **减速只拉移动段**。罚站时间不受减速影响。0.5 倍速下 32.00s → 48.00s
    而不是 64.00s，因为 122 秒罚站一分不动
  - **飞行单位不吃地面阻挡**，箱子对 FLY 路线无效
  - **被踢的敌人**可以直接恢复，不用重新载图
- 重算开销实测 0.83 ms（main_16-11，8 条路线），放箱子即时反馈无卡顿
- 棋子全部走动态层渲染，反复放箱子不会重建静态底图（否则拖动会掉帧）

**新增：肉鸽（集成战略）地图**
- 以前关卡表里**一条肉鸽关卡都没有**——`stage_table.json` 里根本没有
  ROGUELIKE 类型，`zone_table` 的 `rogue_N` 是空壳
- 改为从 `roguelike_topic_table.json` 单独抽，新增 1033 条：
  IS1 90 / IS2 97 / IS3 99 / IS4 293 / IS5 270 / IS6 184
- 换皮图（`levelReplaceIds`）单独列出 258 条，标「换皮图」
- 关卡文件路径按 `levels/ + levelId 小写` 推导，498 个 levelId 全部验证可用
- 关卡目录 3488 → 4521 条

**怪物图鉴：多形态技能名补配**
- PRTS 把形态写进技能名（`献祭[初始模式]`、`献祭[狂暴]`），档案里只有裸名
- 新增形态裁决：只在 PRTS **自己写明了**「第一形态 / 初始模式 / 一般模式 /
  初生形态」这类字面标记时才取那一条，并且强制显示为推测级 `≈`
- 实测 +15 条，零回归，不会改变任何已有配对
- 不猜列表顺序：30 个撞车组里「列第一条」与「带初始标记的那条」有 10 组不一致

### 已知情况
- 技能名到 `prefabKey` 的对应还有约 44% 没覆盖：其中大部分是自动/被动技能（PRTS 里初始写 `/`，没有可对齐的数值锚点），剩下是 PRTS 页面缺失或名字与档案不一致的。这些一律留空。
- 肉鸽地图首次打开需要联网下载（单张约 150 KB），之后走本地缓存。
- 沙盘的干员只是一个标记：不参与攻击判定，攻击范围在未选中时按近战 3×3 兜底显示，只用于判断「这里会不会漏怪」，不是精确的攻击范围复算。
